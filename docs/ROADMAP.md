# תוכנית פיתוח בשלבים

> **הכלל המרכזי:** לא עוברים לשלב הבא עד ש**שער השלב** נסגר: כל המשימות מסומנות, כל בדיקות השער עוברות, והמפתחת אישרה. כך כל שלב בנוי על בסיס שכבר הוכח.
>
> כל משימה מפנה להחלטות ב-[ARCHITECTURE.md](./ARCHITECTURE.md). אם משימה דורשת לסטות מהמסמך, עוצרים ומעדכנים קודם את המסמך.

## איך עובדים עם הקובץ הזה

- כל משימה: מזהה (`S1-T3`), מה בונים, קבצים, **קריטריוני קבלה**, ואיך בודקים.
- משימה מסומנת `[x]` רק אחרי ש-`/verify` עבר במלואו.

- **סטטוס נוכחי** מעודכן בכל סגירת משימה.
